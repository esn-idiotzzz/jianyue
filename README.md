# 简阅 5.3.1

简阅是 Android 漫画阅读应用，提供本地书架、JM 漫画入口、中文图源搜索与浏览、下载和阅读历史。阅读器和图源运行框架基于 Mihon，JM 接口与图片还原参考 JMComic-Crawler-Python，内置扩展来自 Keiyoushi；各项目的来源、用途和许可证见下方说明。

- 项目：[esn-idiotzzz/jianyue](https://github.com/esn-idiotzzz/jianyue)
- 下载：[最新正式版](https://github.com/esn-idiotzzz/jianyue/releases/latest)
- 系统：Android 8.0 及以上，`arm64-v8a`
- 包名：`com.joe.jmlite`

## 5.3.1 更新

- 内置浏览器键盘优化：WebViewActivity 固定使用 `adjustResize`，Android 15 及以上在网页区域补上 IME 内边距，键盘弹出时不再由系统整体平移窗口，输入过程中页面只随可见区域稳定收缩，减少整屏上下跳动。
- 网页输入框获得焦点时，键盘只占用页面下方空间，工具栏、关闭按钮和页面滚动位置保持稳定。
- 图源灰度改为只在完全关闭应用（从后台删除任务或进程重启）后重置；普通切到后台再返回不再清空，同一次使用中的访问标记保持不变。
- 手机与平板的内置浏览器使用同一套修复，其他页面布局不变。
- 版本号提升到 5.3.1（versionCode 39）。

## 5.3.0 更新

- 平板横屏下载页不再被拉宽：大屏设备（包括 `smallestScreenWidthDp` 接近 600dp 的高密度平板）按平板布局处理，下载页从首帧起就使用与仓库页相同的 18dp 外边距和 760dp 内容宽度上限并居中，不再先铺满整屏、点击输入框后才变窄。
- 点击 JM Comic 输入框时，下载页会自动滚回头部输入区域，键盘弹出后仍能看到正在输入的编号框；搜索全网漫画输入框保持原有行为。
- 内容限宽在页面创建时直接应用，避免首帧宽屏闪动和一次多余的布局；GridView 列数仍只在窗口宽度变化时重算。
- 手机设备继续使用手机规则，书架、搜索和下载页布局不变。
- 版本号提升到 5.3.0（versionCode 38）。

## 5.2.3 更新

- 取消 5.2.2 的平板下载页“记住键盘高度、收起后保持较矮布局”：恢复上一版平板下载页布局，键盘弹出时按原逻辑收紧，收起后恢复全高。
- 平板下载页左右留白与仓库页一致：横屏和竖屏都使用与仓库页相同的 18dp 外边距与 760dp 内容宽度上限并居中，列表、卡片和搜索框左右对齐。
- 点击输入框时改用忽略可见性的系统栏内边距，横屏和竖屏下左右排布间距不再随键盘弹出或收起变化。
- 流畅性：GridView 只在内容宽度变化时重新计算列数；内容限宽参数只解析一次；移除 5.2.2 遗留的键盘高度状态和偏好键。
- 手机端下载页保持原有 20dp 外边距和行布局不变。
- 版本号提升到 5.2.3（versionCode 37）。

## 5.2.2 更新

- 平板下载页在首次点击输入框、键盘弹出后记录键盘高度；收起键盘后，下载页继续保持这个较矮的布局高度，不再弹回全高，也不会因键盘反复变形。
- 该高度按 dp 保存，重新进入应用后仍然生效；切换标签或旋转后按当前窗口重新应用，最大不超过窗口高度的 60%。
- 手机端布局与键盘行为保持原样。
- 版本号提升到 5.2.2（versionCode 36），其余功能不变。

## 5.2.1 更新

- 内置浏览器右上角的三点菜单改为一个刷新图标：点击后刷新当前正在浏览的网页，保留当前页面和返回栈，不会跳回图源首页，也不会重新从首页开始加载。
- 移除“网址信息”和“去广告拓展”两个菜单入口；去广告规则固定开启，不再提供关闭开关、二次确认或 114514 解锁流程。
- 版本号提升到 5.2.1（versionCode 35），其余功能和页面保持不变。

## 5.2.0 更新

- 平板自适应：书架、历史和全网搜索的封面网格根据当前应用窗口宽度自动计算列数和封面尺寸。手机（`smallestScreenWidthDp` 小于 600dp）在任何窗口尺寸下都沿用原手机规则（书架 3～6 列、搜索 3 列，封面大小、比例、间距、标题与信息行不变），手机横屏也不会被当成平板；平板窗口窄于 600dp（如分屏）同样使用原规则，窗口达到 600dp 后按目标封面宽度 132dp 计算列数，并把实际封面宽度限制在 104～168dp（搜索 104～176dp），不写死 3/4/6 列，也不整体放大手机界面。
- 平板横竖屏、分屏和自由窗口：GridView 在每次测量时按真实内容宽度重新决定列数，封面高度跟随实际列宽和原比例计算，窗口变化后自动重排；旋转导致页面重建时保留书架滚动位置，并将书架、历史恢复到原来的标签和书籍夹。
- 页面宽度：下载、全部下载记录、漫画详情、在线漫画详情和仓库图源列表在平板宽窗口下限制内容宽度并居中，手机宽度保持原来的左右边距和行布局。
- 阅读器：继续使用 Mihon 原有实现和状态保存，横竖屏均保持漫画图片原始比例与阅读设置，不新增双页模式或修改翻页、缩放、进度逻辑。
- 内置浏览器移除翻译插件：删除“译”按钮、翻译面板、`JYTranslate` 注入、翻译用户脚本、jQuery、CryptoJS 及对应混淆保留规则；右上角菜单保留“网址信息”和“去广告拓展”。
- 图源灰度：图源访问记录改为会话级。每次启动应用、或应用退到后台后重新进入时清空访问记录，仓库图源、检测失败列表和搜索失败列表中的小地球与整行灰度全部恢复；同一次使用中点击过的图源仍保持灰度。
- 版本号提升到 5.2.0（versionCode 34），沿用原包名、发布签名和 `arm64-v8a`。

## 5.1.0 更新

- 内置浏览器右上角新增蓝色“译”按钮，按需加载内置的「网页中英双显互译」脚本：可选择关闭、转中文、转外文、双显，控制译文高亮、自动翻译、选词翻译，并可打开脚本自带的引擎设置。翻译方向只能选一个，自动与选词互斥，开启一个会自动关闭另一个。每次进入新页面翻译默认关闭，不自动开启。
- 去广告拓展关闭改为输入恶臭数字 114514；输入正确才会关闭并重新加载页面。
- 仓库搜索图源下方的图源数量行最右侧新增主题蓝字“检测图源”，位置不越过上方搜索框右边缘。点击后提示“请确认已开启魔法”，选择“已开启”后在后台用“1”搜索全部仓库图源，显示搜索进度条；不展示漫画封面，完成后列出失败的图源。
- 检测失败图源、下载页“搜索全网漫画 → 点击查看”的失败图源统一为同一套行布局：右侧只有小地球按钮，没有收藏爱心；点击地球打开对应图源网站，点击过的图源整行灰度显示。仓库图源、检测图源和搜索失败图源共用同一份图源数据和访问状态，登录状态也共用同一 WebView Cookie。
- 流畅性：翻译组件只在首次打开“译”面板时注入，并在注入时隔离网页自身的 jQuery/CryptoJS，避免覆盖图源网站原有脚本；翻译请求线程池在进程内复用；失败列表复用仓库图源行和图标缓存；图源访问状态通过共享偏好一次写入、所有入口同步刷新。

## 5.0.3 更新

- 非系统书籍夹的自动收起增加当前目录保护：用户仍停留在只剩 1 本书（或已空）的书籍夹里时，先不拆除书籍夹，页面保持稳定；返回上一级后才自动收起，0 本删除书籍夹，1 本把书放到所在目录的最后。
- 返回时先在界面数据中应用收起结果，再在后台落盘并刷新，父级书架直接以收起后的状态出现，不会先闪出书籍夹再消失。
- 三个系统书籍夹（我的收藏、在线JM漫画、在线全网漫画）仍然不参与自动收起；普通书架和隐私书架使用同一规则，所有层级的非系统书籍夹都适用。
- 切换底部标签离开书籍夹时，同样会释放并收起该书籍夹。
- 在普通书架或隐私书架的书籍夹内，把最后一本书拖到下方胶囊“移出书籍夹”时，松手后自动返回上一级并拆除这个书籍夹（系统书籍夹除外）。

## 5.0.2 更新

- 除“我的收藏”“在线JM漫画”“在线全网漫画”三个系统书籍夹外，书籍夹在失去书籍后自动收起：夹内为 0 本时删除书籍夹；为 1 本时删除书籍夹并把这本书放回书籍夹所在目录的最后；有子书籍夹时按整个子树的书籍数判断，子书籍夹一并收起。普通书架和隐私书架使用同一规则。
- 下载页的“开始下载”和“在线阅读”都会先检查书架、隐私书架是否已有同编号的本地书籍：有则弹出同一个“书架已有此书籍，是否跳转其位置？”提示，按钮为“取消/跳转”。
- 点击“跳转”后进入对应书架并自动滚动到该书，封面显示蓝色描边；用户滑动或点击屏幕后描边消失。
- 修复已有下载任务时点击“开始下载”先提示暂停、看不到书架已有书籍提示的问题；现在先判断本地书籍，再检查下载任务。

## 5.0.1 更新

- “我的收藏”“在线JM漫画”“在线全网漫画”三个系统书籍夹不再提供拆除，避免误删系统目录；其他书籍夹无论夹内是 0 本、1 本还是多本，拆除后夹内书籍统一放回书籍夹所在目录，夹中夹一并拆除。
- 书籍拖动判定调整：书籍中间的合并区扩大到左右各 12% 的边缘之外，只有在卡片两侧窄条或空隙停留后才触发推走，减少想合并书籍夹时把书推走的情况。
- 合并或放入书夹时保持目标卡片停在手指下方，不再因补位把目标滑走；离开目标后仍会正常补位。
- 补位与推走动画从 190ms 调整为 250ms，并改用更平缓的缓出曲线，让位更从容、停住更柔和。

## 5.0.0 更新

- 书架长按拖动书籍或书籍夹时，卡片一旦离开原位置，后面的书籍和书籍夹会立即补位，不再空在原处；拖动经过可放置位置时仍保留原有的推动让位效果，落点空位随手指平滑移动。
- 拖到所有书籍之后或书架空白处松手，会把书籍放到该目录的最后一个；书籍夹会放到其他书籍夹的末尾，书籍仍排在书籍夹之后。
- 补位与推动共用一段 190ms 减速动画，并只重新指向目标位置变化的条目，快速划过多个落点时不会反复重启没有变化的动画；边缘自动滚动改为每 16ms 小步推进，落点跟随更连续。
- 拖动松手后不再额外刷新整架书架，写入完成后的强制刷新直接接管新顺序，避免旧顺序闪回和重复加载。
- 历史页在线列表改为复用行视图和文字，滚动时不再逐行创建整行布局；书架刷新改用 StringBuilder 指纹，减少每次刷新的 JSON 对象分配；书架绑定不再对相同文字重复触发布局。
- 拆除书籍夹会连同夹中夹一起拆除：主书籍夹及其所有层级的子书籍夹全部删除，夹内书籍统一放回主书籍夹所在的上一级（书架根目录或上一级书籍夹）。书籍夹内拖到底部胶囊的“拆除书籍夹”使用同一规则。

## 4.5.1 更新

- 书架内书籍与书籍夹的排列间距对齐仓库图源热门列表：左右内边距 18dp、顶部 4dp，横向间距 10dp，纵向间距 16dp，列宽按同一套参数计算。
- 封面与书名间距从 9dp 调整为 6dp，书名改为 12sp 两行；附加信息改为 10sp 一行并保留一行高度，空信息不再占两行，行高和本地书、在线书保持一致。

## 4.5.0 更新

- 删除书籍夹按层级处理：书籍夹中夹删除后，夹内书籍回到上一级书籍夹，子书籍夹也上移一级；只有书架根目录的书籍夹删除才把书籍放回书架。删除确认文案随层级变化。
- 我的收藏整理规则统一：我的收藏目录及其任意层级的子书籍夹中的书籍都保持已收藏状态；拖动、分类、合并、创建子书籍夹和隐私书架转移都会写入收藏状态。
- 长按拖动书籍到书籍夹上方时，蓝色描边只画在封面区域，不再框住下方的书籍夹名称。
- 长按拖动书籍到另一本书上方时不再直接显示书夹并露出底层封面：被拖到的书籍先平滑变形成书籍夹预览（封面淡出、书夹拼贴淡入并回弹缩放），松手后才把拖动的书放进去；与拖到书籍夹上的描边、缩放和时长统一。
- 书籍夹在书架上的 2×2 预览可显示夹中夹：子书籍夹按书籍位置递归显示自己的封面拼贴，数量为直接书籍与子书籍夹之和，夹内变化会刷新外层预览。
- 在书籍夹内确认进入拖动后，底部胶囊导航变为投放区：拖书籍时显示“拖动到此移出书籍夹”，拖书籍夹时显示“拖动到此拆除书籍夹”；悬停时胶囊轻微放大。放入后书籍回到上一级列表，或把子书籍夹中的书籍放回当前列表并删除该书籍夹。仅长按、尚未开始拖动时不改变胶囊。

## 4.4.0 更新

- 书架长按书籍或书籍夹不再一按住就进入拖动：长按先只进入按住状态，松手时未移动就直接打开菜单，不再出现松手先取消拖动、再弹出菜单的顿挫和卡片闪回。
- 长按后手指移动超过触摸阈值才开始拖动排序、拖到另一本书建立书夹、拖到书夹直接放入；未移动松手打开菜单保留轻微回弹与菜单淡入的连续过渡。
- 短按阅读、拖动排序与合并、搜索展开时长按、隐私书架及历史页原有长按入口保持可用。

## 4.3.0 更新

- 书架长按书籍或书籍夹后松手，菜单不再瞬间弹出：被按住的卡片先回落到原位，菜单随后淡入并轻微放大，窗口遮罩同步渐显，消除了松手瞬间的明暗跳变和卡片闪回。
- 打开菜单前不再整块刷新书架网格，卡片回落与菜单展开连续衔接；长按拖拽排序、拖到另一本书建立书夹、拖到书夹直接放入等手势保持不变，仍是松手未移动才打开菜单。
- 搜索展开时直接长按书架卡片打开菜单的路径也使用同一套过渡，书籍与书籍夹保持一致；历史和下载页的长按行为不变。

## 4.2.0 更新

- 修复全网搜索“点此查看”失败图源弹窗只显示外框、不显示列表的问题：明确分配弹窗高度，列表随可用空间布局，打开时不自动弹出键盘，补齐运行时图源 ID 到仓库条目的映射。
- 失败列表继续共用仓库行布局、图标、地球登录和收藏；无失败或搜索无匹配时显示空状态。
- 仅书架的长按触发等待缩短到 300 毫秒；仍需松手才打开菜单，移动继续拖动排序、合并，历史的长按时长与效果保持原样。

## 4.1.0 更新

- 书架、隐私书架、历史和下载记录采用与仓库图源一致的原生滚动与条目复用方式；书籍换绑时复用封面视图，保留同一本书已显示的封面，减少滚动中的视图创建和重复清空。搜索与图源浏览继续使用原生列表和封面复用。
- 快速滑动取消触摸时，仅在确有缩放时恢复条目，避免空回弹动画。
- 修复下载页首次点击 JM / 全网输入框后键盘弹出却丢失光标：键盘缩放后的表头焦点恢复到用户最近选择的输入框。

## 4.0.0 更新

- 书架与搜索结果统一书籍条目高度，滚动回收时清理按压缩放，修复快速上下滑动时的轻微错位。
- 全网搜索复用封面视图，保留已经显示的图片；新增最多 128 MiB 的封面磁盘缓存，内存缓存淘汰后优先从本地读取。

## 图源网站与登录

仓库每个图源的收藏爱心左侧提供地球入口，打开该图源自身的首页，供浏览和登录使用。热门列表加载状态下方保留登录提示说明，搜索本图源时隐藏。明确返回登录要求时显示可点击的悬浮胶囊；超时、普通 403 和空列表不会被当成登录要求。从登录提示打开网站后也回到仓库，重新点击图源加载列表。浏览器与采用共享 Cookie 的图源共用登录状态；使用独立 API 令牌或扩展账号设置的图源仍取决于自身实现。

登录窗口没有底部导航栏，首页返回仓库，内页使用系统返回。右上角只有一个刷新图标：点击刷新当前网页，不会跳回图源首页，也不影响已打开的页面和返回栈。去广告规则固定开启，没有关闭开关，也不再提供“网址信息”菜单。

去广告内置用户指定的 [其他.prop 规则](https://ghfast.top/raw.githubusercontent.com/lingeringsound/adblock_auto/main/base/%E5%85%B6%E4%BB%96.prop)，快照版本 `20261104121737`。实现标准 CSS 元素隐藏和常用 ABP 网络规则，包括站点范围、资源类型、第三方限制及白名单；不执行规则中的脚本注入，不支持的修饰符和程序式选择器会跳过。规则仅作用于内置网页，不修改图源 API、搜索或阅读请求；当前随应用更新，不后台自动更新。

## 构建

需要 JDK 21、Android SDK platform `37.2`、Build Tools `37`，首次构建需要网络下载 Gradle 和 Maven 依赖。

```powershell
.\build-mihon.ps1 -JavaHome C:\path\to\jdk21 -AndroidHome C:\path\to\android-sdk
```

输出位于 `build/`。项目不发布签名私钥、签名密码或本机工具链。构建脚本在没有本地密钥时会生成自己的签名；这种签名不能覆盖安装官方发布包。发布维护者须妥善保留原签名。

应用源码位于 `app/src/main/`，Mihon 适配工程位于 `mihon/`。当前 JVM 逻辑测试位于 `mihon/app/src/test/`；`tests/java/` 和 `build-legacy-tests.ps1` 为旧测试，不作为当前验证结果。每版实际构建、测试和设备验证边界以该版 Release 随附验证说明为准。

## 发布后如何触发更新

1. 提升应用版本名及 `versionCode`，例如 `3.8.0` → `3.8.1`，并用相同发布密钥签名。
2. 在本仓库创建对应 GitHub Release，使用可比较的标签，例如 `v3.7.2`，填写更新说明，同时上传 APK 和构建脚本生成的 `build/update.json`。公开 APK 名称须与元数据中的 `JianYue-版本-arm64-v8a.apk` 一致。
3. 将它发布为最新正式版。草稿和预发布不用于正式版更新提示；Release 正文会显示在应用更新弹窗里。
4. 已安装支持更新检查版本的手机在下次打开应用时检查版本。仅推送源码、创建空标签或上传到其他仓库不会触发更新。

检查更新需要手机能访问 GitHub。3.7.0 起优先读取最新正式 Release 附带的更新元数据，减少对匿名 API 配额的依赖；元数据缺失或无效时回退 API。每次打开检查一次，主元数据通道失败时尝试API；限流时遵守服务器要求。应用不自动下载或安装 APK。尚未含有此功能的 3.1.0 需要先手动安装 3.3.0 或更高版本。
